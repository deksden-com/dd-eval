Продолжи обычный flow со стадии CODE. Выполни зарегистрированный граф работ в
предусмотренном порядке: каждую работу делегируй свежему агенту, принимай её
только через штатный `work finish`, устраняй выявленные проверки через repair
work и заверши общий гейт CODE. Остановись сразу после успешного `stage finish`
для CODE; следующую стадию не начинай. Не считай тишину или долгий tool-вызов
признаком зависания: не прерывай работающего агента, пока harness явно не
покажет терминальное состояние или запрос внимания.
