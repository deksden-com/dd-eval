# REV-107 — непригодная каноническая цепочка

Цепочка остановлена после PLAN-REVIEW. Ранняя часть успешно прошла SPECIFY,
PROTOCOLIZE и PLAN, а independent review улучшил техническую верификацию, но
не защитил связанный сценарий `SCN-002` от semantic drift. Это дефект
инструкций PLAN/PLAN-REVIEW, а не повод менять уже материализованные артефакты
REV-107 задним числом.

Новая каноническая цепочка должна начинаться из неизменённого source checkout
с парой beta.134; REV-107 остаётся доступным только для сравнения и анализа.
