# Принятие SPECIFY: REV-106

## Решение

Принято как каноническая входная граница для `PROTOCOLIZE`.

## Основания

- Результат фиксирует все четыре канонических значения и default/backfill без
  добавления несуществующего жизненного цикла архивирования задач.
- R-001…R-007 и AC-001…AC-005 покрывают сохранение порядка, границу
  priority-only для архивного проекта и действующую авторизацию workspace.
- Передача в `PROTOCOLIZE` содержит ограниченный scope, применённые методы
  выявления пробелов, источники, проверочные семена и явное отсутствие
  открытых пользовательских вопросов.
