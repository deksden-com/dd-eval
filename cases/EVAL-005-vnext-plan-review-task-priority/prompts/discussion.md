# Обсуждение фичи

Нужно добавить приоритеты задач: пользователь выбирает приоритет при создании
и редактировании задачи и видит его в списке. Если для поведения нет
безопасного разумного дефолта, задай вопрос; иначе зафиксируй дефолт.

Пока не оформляй работу. После следующего сообщения пользователь попросит
оформить протокол.
