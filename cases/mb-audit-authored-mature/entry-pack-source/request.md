Проверь applicability всех 12 аспектов и явно объясни пропуски, ограничения и
неизвестное. Особое внимание удели достоверности текущих утверждений,
навигации и ссылкам, соответствию исходникам и уже принятым named DEF.
Отличай реализованное поведение от требований, планов и заявлений документации.

Сохрани исходные файлы, Memory Bank, Git index, права и ссылки без изменений.
Не исправляй найденное, не закрывай DEF и не запускай проектные тесты, сборки,
установки или миграции. Исходники и тесты можно читать как данные.
Разрешены выданные управляющим RUN команды lifecycle CLI и запись его отчётов.
Исторический flow pack внутри проекта не заменяет установленный flow этого RUN.

Подготовь отчёт на русском с проверяемыми findings, applicability, источниками,
результатами независимой критики и ограничениями. Успешное завершение RUN само
по себе не означает, что проект чист или что найденное исправлено.
