# Первичный запрос

Добавьте приоритет задач. Приоритет нужно выбирать при создании и редактировании задачи и видеть в списке задач.

Сначала пройдите проектный flow `protocol -> specify -> plan`. На стадии `specify` выявите существенные пробелы задачи и задайте необходимые вопросы. До получения ответов к реализации не переходите.
