## Substantial review fixes

1. Shared shutdown publication still wrote `active_tree:false`. Activity landing
   during the durable write could be erased, especially on adapters without an
   AGY-style revision counter. Removed the stale write; prepare owns quiescence.
   The regression failed before the fix and passes afterward. A late event now
   invalidates clean/native settlement while retaining physical-stop truth.
2. Engine retained resume/recovery and EVAL daemon replacement accepted a shutdown
   without comparing it to the current operation generation fence. Both now bind
   the shared validator to exact daemon/generation. Missing, foreign or advanced
   fences cannot authorize reuse of a stale clean receipt. Directed regressions
   cover an advanced fence; existing valid same-generation recovery still works.
3. Native P3 originally sampled only the root-event-time descendant cache. Child
   transcripts grow without root events, so the probe missed a real grandchild.
   It now refreshes the existing bounded source-bound recursive capture. The
   fixture asks for single tool calls, avoiding invented FIFO correlation, and
   lets root/child reply locally before their descendants finish.
4. Found and exercised native `ForceStopCascadeTree` in AGY 1.4.6. Its two protobuf
   message descriptors are generated by the existing generator, not hand-coded
   wire parsing. Control uses the same owned loopback endpoint, CSRF and native
   root/workspace binding as inspection; unknown/missing/duplicate stopped IDs
   are rejected. A control ACK is never an idle/physical/clean grant.
5. Typed service shutdown can use that native control **only after complete
   matching P3 qualification**. It rechecks native idle, endpoint incarnation and
   execution revision, retains the productive outcome, then leaves physical
   process/birth retirement to shared shutdown. Unqualified binaries and unknown
   classification retain their blocker. Deterministic tests cover qualification,
   late activity and outcome preservation. This is not a live qualification of
   the complete production route.
6. Probe retirement PASS now also requires successful native stop, absent owned
   task PID/birth and a post-stop native idle observation. A later OS fallback
   alone can no longer masquerade as successful native control.

## P3 decision

**BLOCKED, not complete; no authority receipt minted.** The native control
primitive and important live cases are now established, but the strict existing
P3 requirements for terminal-parent/live-child, terminal-child/live-background,
and isolated grandchild-only execution plus explicit completion-pending inventory
are not all represented by independently sufficient native facts. Busy samples
and local replies must not be relabelled into those stronger terminal facts.
The validator was not weakened and old evidence was not upgraded in place.

Next bounded work is native per-node execution/delivery evidence (or an explicit
review of that acceptance model if native local-turn completion is the intended
meaning of terminal). No further ordinary EVAL or full release gate is needed
to answer that capability question. Access/quota is not the current blocker.
